# 夜市人生 | Nightmarket Life
#### Unity-based Android Mobile Game Project
## プロジェクト概要 | Project Overview
本プロジェクトは、台湾独自の「夜市文化」をデジタルゲームを通じて世界に発信したいことから開発を着手しました。<br>
場所を問わず、スマートフォンを通じて台湾夜市の賑やかな雰囲気や楽しいミニゲームを体験できる作品を目指しました 。
#### 主な特徴：
  - **文化体験**<p>
  「輪投げ」や「地瓜球（サツマイモボール）作り」といった、台湾夜市の定番ゲームを忠実に再現しています 
  - **体感型操作**<p>
  Android の加速度センサーを活用し、直感的な物理操作を実現
  - **ランダムな探索要素**<p>
  ゲーム内ではストリートミュージシャンがランダムに出現し、探索の楽しさと意外性を高めています

## ゲームプレイとフロー | Gameplay Flow
ゲーム開始後、プレイヤーは主に 4 つのインタラクティブなフローを体験できます。
- **輪投げ (Ring Toss)**： 加速度センサーを利用し、実際にスマートフォンを振る動作で輪を投げます 。景品を獲得すると「コレクション図鑑」に追加されます 。
- **さつまいもボール作り (Sweet Potato Balls)**： リズムアクション形式のゲームです 。画面をタイミングよくタップしてヘラを動かし、回転する地瓜球をプレスしてコインを稼ぎます 。
- **コレクション図鑑 (Collection Book)**： 獲得した景品を確認できるモードです 。景品をクリックすると拡大表示され、そのアイテムに関する簡単な紹介文を読むことができます 。
- **ランダムイベント (Random Events)：** メインシーンにストリートミュージシャンがランダムに出現します 。投げ銭を贈るかどうかを選択できます。
  - **いいえ**：メインシーンに戻ります
  - **はい**：ランダムで 2 つの状況が発生します。
    - 投げ銭としてコインを失う
    - お返しとして景品を獲得できる
