# 夜市人生 | Nightmarket Life
#### Unity-based Android Mobile Game Project
## プロジェクト概要 | Project Overview
本プロジェクトは、台湾独自の「夜市文化」をデジタルゲームを通じて世界に発信したいことから開発を着手しました。<br>
場所を問わず、スマートフォンを通じて台湾夜市の賑やかな雰囲気や楽しいミニゲームを体験できる作品を目指しました。
#### 主な特徴：
  - **文化体験**<p>
  「輪投げ」や「地瓜球（サツマイモボール）作り」といった、台湾夜市の定番ゲームを忠実に再現しています 
  - **体感型操作**<p>
  Android の加速度センサーを活用し、直感的な物理操作を実現
  - **ランダムな探索要素**<p>
  ゲーム内ではストリートミュージシャンがランダムに出現し、探索の楽しさと意外性を高めています
  - **コレクション要素**<p>
  獲得した景品はコレクション図鑑で詳細を確認可能

## ゲームプレイとフロー | Gameplay Flow
ゲーム開始後、プレイヤーは主に 4 つのインタラクティブなフローを体験できます。
- **輪投げ (Ring Toss)**：<br>
  加速度センサーを利用し、実際にスマートフォンを振る動作で輪を投げます。景品を獲得すると「コレクション図鑑」に追加されます。
- **さつまいもボール作り (Sweet Potato Balls)**：<br>
  リズムアクション形式のゲームです。画面をタイミングよくタップしてヘラを動かし、回転する地瓜球をプレスしてコインを稼ぎます。
- **コレクション図鑑 (Collection Book)**：<br>
  獲得した景品を確認できるモードです。景品をクリックすると拡大表示され、そのアイテムに関する簡単な紹介文を読むことができます。
- **ランダムイベント (Random Events)**：<br>
  メインシーンにストリートミュージシャンがランダムに出現します。投げ銭を贈るかどうかを選択できます。
  - **いいえ**：メインシーンに戻ります
  - **はい**：ランダムで 2 つの状況が発生します
    - 投げ銭としてコインを失う
    - お返しとして景品を獲得できる
## 技術的実装と工夫 | Technical Implementation & Key Highlights
1. **加速度センサーを用いた直感的な操作**<p>
「輪投げ」ステージでは、スマートフォンの加速度センサー（Input.acceleration）を活用しました
    - **課題**：センサーの生データを直接投擲軌道に変換することが技術的に困難でした
    - **解決策**：実際にデバイスを振った際の数値をログで詳細に分析し、特定の動作に対応する値を割り出しました。<br>
    この数値を「左・中央・右」の 3 つの判定区間に分類し、対応するアニメーションを再生することで、プレイヤーに違和感のない投擲体験を提供しました。<p>
2. **シーン管理と共通化**
  - 複数のゲームシーンを管理するため、外部から遷移先を指定できる汎用的なスクリプトを構築
  - **Transitionの共通化**：アニメーション付きの遷移を Prefab 化し、どのシーンからでも容易に呼び出せる設計にすることで、開発効率を向上させました。
3. **データ永続化**<p>
    獲得した景品や所持金などのゲーム進捗は PlayerPrefs を用いて管理し、Android デバイス内への確実なデータ保存を実装しました。
4. **チーム開発におけるワークフロー**<p>
    開発初期段階で詳細な **Storyboard** を作成し、プログラマーとデザイナー間の認識を合わせた。<br>
    これにより、UI ボタンの配置や画面遷移のロジックに関する手戻りを最小限に抑えました。

## インストール方法
1. 本リポジトリの [Releases](https://github.com/chenyi092/Nightmarket_Life/releases/tag/v1.0.0) ページから最新の .apk ファイルをダウンロードしてください。
2. Android 端末にファイルを転送します。
3. 端末の設定で「不明なソースからのアプリ作成」を許可してください。
4. .apk ファイルを実行し、インストールを完了させてください。
